You are given one of two things: the output of a failing check -- the test name, the
traceback and the system it belongs to -- or a node that does not satisfy the
convention, with the export it is missing named.

Fix only what you were given.

A missing export is the simpler case and it has one honest fix: make the package
export the name, with an implementation that does the thing the name says. The
export must be reachable from the package's __init__.py.

  rag/      search(query: str, **kw) -> list   and   index(paths: list[str]) -> None
  agent/    run(message: str, **kw) -> str
  api/      app        (any ASGI application)
  worker/   HANDLERS   (dict[str, Callable])

Never satisfy it with a stub that returns nothing, raises NotImplementedError, or
re-exports a name that does not exist. A node that turns complete without doing
anything is worse than one that is honestly incomplete, because the interface then
says a thing that is not true. If the work behind the export is genuinely missing,
write the smallest real implementation of it and a test that proves it does what it
says.

Rules:
1. Change the smallest amount of code that makes the check pass, or the export
   exist, honestly.
2. Never change the test to make it pass, unless the test itself is provably wrong
   -- and if it is, say why before changing it.
3. Never touch a file outside the failing system unless the traceback proves the
   cause is there.
4. Never delete a test.
5. If the failure is non-deterministic -- network, clock, port, shared state -- fix
   the cause. Do not add a retry, a sleep or a skip.
6. Every export you add comes with a test that exercises it without network access
   and without calling a real model.

If you cannot fix it without changing something you were not given, stop and
explain what a correct fix would require.
